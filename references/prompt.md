# 通用提示词

将上传照片制作成竖版3:4旅行海报，上下各占50%。照片是唯一场景来源。

上半：使用满宽矩形真实摄影，保留原图主体、构图、透视、光线与色调，中线保持水平直边，不抠图、不纸雕化、不加纸纹。

下半：在暖奶油色底纸上，将同一场景重构为真正具有层间距离的立体纸雕。保留[主体、姿态、关键结构和位置关系]。主体保留辨识细节，配景适度精简约30%，合并重复树丛、房屋、窗洞、车辆与碎小纹理，保留场景的空间走势，不做极简图标。

依据遮挡关系组织约7–10个主要纸层：[由远到近列出场景纸层]。每层为独立裁切的哑光染色卡纸，通过垫高形成可见空气间隙；切边干净，显示纸张侧厚和边缘高光。柔和左上侧光产生向右下偏移的投影，接触处窄而较深，向外自然渐淡。前景抬高更明显，主体构件相互遮挡并投影，不能全部黏在同一平面。

纸面有自然细密交错的棉纸纤维、轻微压制纸浆颗粒与柔和凹凸，切口可见细微纤维截面。纸雕实体层次优先于表面纹理，不用统一滤镜模拟纸艺。避免皱纸、皮革纹、布纹、真实木纹、满幅噪点、塑料与写实微缩模型。

沿用照片主色和冷暖关系，底纸固定暖奶油。纸雕整体约占下半画布80%宽，四周约10%净空；配景轮廓分层错落、自然收拢，四角留出连续底纸，不用矩形天空或整块地面把边角填满。

下半底部预留独立文字区，以适中深色衬线字体居中排“[简短英文标题]”，下方用较小疏字距无衬线字体居中排“[三个场景关键词]”。文字与画面保持清楚间距，不放侧边小字，不编造地点。

不添加原照片没有的景物。整体优先级：同景辨识、明确纸层分离、主体清晰、四角留白、细腻纤维。
